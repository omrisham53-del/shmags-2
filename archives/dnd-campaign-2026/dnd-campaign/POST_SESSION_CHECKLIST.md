# Post-Session Context Update Checklist

**Use this after EVERY D&D session to keep campaign context updated for future conversations**

---

## Before Starting Next Session

After you play a D&D session, go through this checklist and update the campaign files. This ensures I have fresh context.

### 1. Session Notes
- [ ] What happened this session? (Brief summary)
- [ ] Which scenes were played?
- [ ] What did players discover?
- [ ] Any new NPCs introduced?

**Where to save:** Add to `sessions/session-X-notes.md`

---

### 2. Player Character Updates
- [ ] Any character development moments?
- [ ] New motivations revealed?
- [ ] Relationships with NPCs changed?
- [ ] Character-specific discoveries made?

**Action:** Update `npcs-and-characters.md` - "Player Characters" section with new insights

---

### 3. NPC Updates
- [ ] New NPCs introduced? (Add to file)
- [ ] Existing NPC behavior/personality revealed?
- [ ] NPC relationships with party changed?
- [ ] Hints about antagonists given?

**Action:** Update `npcs-and-characters.md` - "NPCs" section

---

### 4. Story Progress
- [ ] Did players advance the main plot?
- [ ] New clues about the betrayer?
- [ ] Revelation about dragon riders or lore?
- [ ] World-building added?

**Action:** Update `campaign-arc.md` with new discoveries

---

### 5. Rules/Mechanics
- [ ] Any new magical items found?
- [ ] New enemies encountered? (Get stats if possible)
- [ ] Abilities/powers used that should be documented?
- [ ] Mechanical clarifications needed?

**Action:** Create new file or update existing: `mechanics-and-items.md`

---

### 6. World/Lore Updates
- [ ] New locations discovered?
- [ ] Historical details revealed?
- [ ] Setting atmosphere changes?
- [ ] Cultural elements added?

**Action:** Update `world-lore.md` with new information

---

### 7. Relationship Map
- [ ] How do players feel about each NPC now?
- [ ] Party unity status?
- [ ] Trust levels changed?
- [ ] Conflicts or alliances formed?

**Action:** Create new file if needed: `relationships.md`

---

### 8. Memory Update

At the end, just message me:

> "Session [X] complete. Updated campaign files - [brief summary of changes]. Ready for next session."

I'll verify the files and ask clarifying questions if needed.

---

## Why This Matters

- I don't have to re-learn the campaign every conversation
- Character arcs stay consistent
- Plot details don't get lost
- NPC personalities remain coherent
- You get to focus on DMing, not explaining lore
- Future session prep is 10x faster
