# Academic Research Repository

This folder stores research findings and notes from university coursework and academic projects.

## Organization

Each assignment or research topic gets its own subfolder:
```
academic/
├── hw2-lca-milk-production/
│   ├── notes.md
│   ├── sources.md (bibliography)
│   ├── data-verification.md
│   └── [assignment files]
├── [next-assignment]/
└── [research-topic]/
```

## Research Workflow

1. **Create assignment folder** with assignment name and number
2. **Document sources** as you find them in `sources.md` (save DOI links)
3. **Verify data** against peer-reviewed research in `data-verification.md`
4. **Keep notes** on key findings, concepts, and connections
5. **Save final work** to projects/university/notes/ with bibliography

## File Naming

- `notes.md` - Research notes, key findings, connections
- `sources.md` - Bibliography in APA format (keep synced with work)
- `data-verification.md` - Track what was verified against peer-reviewed sources
- `citations.txt` - Citation list for quick reference

## Research Sources

**Free Academic Databases:**
- Google Scholar (scholar.google.com)
- MDPI (open access journals)
- ResearchGate (researchers share preprints)
- Your university library (often provides paywalled journal access)

**How to Cite:**
- Use consistent APA format across all work
- Include DOI links when available
- Keep bibliography synchronized with in-text citations
