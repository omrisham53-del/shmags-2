# Daily Routine & Workflow

**Purpose:** Structured workflow to maximize focus, minimize context-switching, and maintain consistency.

---

## Morning Routine (30 min)

**Time:** Start of each session

- [ ] Open `today.md` - Review daily priorities
- [ ] Check calendar - Any meetings or deadlines today?
- [ ] Check email - Quick scan for urgent items
- [ ] Set top 3 priorities - What must get done?
- [ ] Update `today.md` with current date and focus
- [ ] Start work timer - 90-min focus block

**Mindset:** Clear, intentional, focused on what matters

---

## Work Session Structure (90 min blocks)

**Format:** 90 minutes focused work, 15 min break

### Before Starting
- [ ] Know what task you're working on (reference `today.md`)
- [ ] Close all distracting apps (email, Slack, notifications)
- [ ] Have required files/tools open
- [ ] Commit to 90 minutes

### During (90 min)
- Single focus on one task
- No context switching
- Don't check email/messages
- If stuck, move to next subtask (don't get blocked)

### After (15 min break)
- Stand up, stretch, get water
- Look away from screen
- Quick walk if possible
- Reset before next block

---

## Daily Work Blocks (Suggested)

**Morning Block 1 (9:00-10:30 AM):** Most demanding work
- University assignments
- Job search deep work
- Analysis/writing that needs focus

**Morning Block 2 (10:45-12:15 PM):** Continued focused work
- Follow-up on Block 1
- Secondary priority
- Planning/organization

**Lunch (12:15-1:00 PM)**
- Real break, away from desk
- Eat properly

**Afternoon Block 3 (1:00-2:30 PM):** Medium-demand work
- Project work
- D&D prep
- Administrative tasks

**Afternoon Block 4 (2:45-4:15 PM):** Lighter/varied work
- Communications (email, messages)
- Job search outreach
- Organization/cleanup

**Evening:** Flexible (meetings, side projects, D&D sessions, etc.)

---

## End-of-Day Wrap (15 min)

**Time:** Before leaving desk or ending work for the day

- [ ] Update `today.md` with what got done
- [ ] Move incomplete items to tomorrow's priorities
- [ ] Note any blockers or issues
- [ ] Update relevant project status files (university, job-search, etc.)
- [ ] Close all work files
- [ ] Clear desk/close laptop
- [ ] Mental note: Done for the day

**Mindset:** Closure, satisfaction of completion, ready to disconnect

---

- [ ] Check all project status files (university, job-search, energy-program)
- [ ] Note learnings or patterns

## Focus Rules

**During work blocks:**
1. One task at a time (no multitasking)
2. No email/Slack/messages (check during breaks)
3. Phone on silent (not visible)
4. Full-screen on your work
5. If stuck for 15 min → switch to different task (don't waste time)

**Protect deep work:**
- Morning blocks are sacred (no meetings if possible)
- Afternoon is for lighter work and communications
- Batch email/messages (check 2-3 times daily, not constantly)

**When interrupted:**
- Note where you are
- Handle the interruption quickly
- Return to work immediately
- Don't let it derail your block

## Energy Management

**High energy times:** Use for most demanding tasks
- Writing, analysis, learning new concepts
- Complex problem-solving
- Strategic thinking

**Medium energy times:** Medium-demand tasks
- Project work, implementation
- Communications
- Organization

**Low energy times:** Low-demand tasks
- Administrative work
- Organizing files
- Routine updates
- Light reading

**When energy is low:**
- Don't force complex work
- Do maintenance tasks instead
- Take a real break
- Come back fresh

## Tools & Environment

**Open during work:**
- Task at hand (assignment, project file, etc.)
- Timer (for 90-min blocks)
- Reference materials if needed
- Minimal tabs (2-3 max)

**Closed during work:**
- Email
- Slack/messages
- Social media
- Unrelated tabs
- Phone notifications

**Physical:**
- Water nearby
- Notebook for ideas that pop up
- Comfortable chair
- Good lighting

## Notes

- This routine is a guide, not rigid law - adjust if something isn't working
- 90-min blocks might be 60-min or 120-min depending on task type

- Friday reviews keep everything aligned and prevent drift
- When blocked on one thing, move to another (don't waste the 90 min)
