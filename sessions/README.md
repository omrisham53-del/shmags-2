# Session Summaries

Organized session notes and summaries from work sessions with Claude Code.

**Naming Convention:** `YYYY-MM-DD_description.md`

## What Goes Here
- End-of-session summaries using the template
- What got done that session
- Decisions made
- Open items and next steps
- Memory updates (preferences, learnings to retain)

## How to Use
1. Use the template in `templates/session-summary.md`
2. At end of session, save as `YYYY-MM-DD_your-focus.md` in this folder
3. Update memory system with any preferences learned
4. Log important decisions in `decisions/log.md`

## Archives
- Move old session summaries to `archives/sessions/` after 30 days or when project completes
- Keep current quarter's sessions here for easy reference
