## The Core Framework

### Step 1: Calculate Metrics
```
CAC = Total Spend ÷ Paying Users
LTV = (D30 ARPU × 12) + Tail Revenue
Ratio = CAC ÷ LTV
```

### Step 2: Compare to Healthy Benchmarks
```
Healthy CAC:LTV = 1:3 to 1:5 (ratio 0.20-0.33)
Healthy D7 Retention = 20-40% (casual) or 40-60% (mid-core)
Healthy Payback = <12 months
```

### Step 3: Diagnose Root Cause
```
IF D1 high, D7 low → Creative fatigue or audience quality
IF D1 low → Product issue (crash, bad UX)
IF LTV low despite good retention → Monetization problem
IF CAC high but LTV good → Premium users, manageable
```

### Step 4: Recommend Action
```
Scale channel if: CAC:LTV ratio < 0.33 AND retention healthy
Reduce channel if: CAC:LTV ratio > 0.50 OR D7 < 15%
Pause channel if: CAC:LTV ratio > 1.0 AND declining
Test if: Problem unclear (propose A/B test to diagnose)
```

## Tips for Success

### Before the Interview
1. **Memorize formulas** - Don't stumble on basic math
2. **Know benchmarks** - What's healthy for D7 retention? (Answer: 20-40% casual)
3. **Practice out loud** - You'll need to explain your thinking
4. **Do mock interviews** - Have a friend ask questions, practice answers

### During the Interview
1. **Ask clarifying questions** - "Is this a casual or mid-core game?" (affects benchmarks)
2. **Show your work** - "First I calculate CAC... then LTV... then ratio..."
3. **Compare to benchmarks** - "CAC:LTV is 0.25, which is excellent"
4. **Diagnose root cause** - "D1 is high so product is OK, D7 is low so probably creative"
5. **Recommend action** - "I'd pause this channel and test fresh creative"

### What They're Looking For
- Can you calculate metrics quickly and correctly?
- Can you interpret numbers (not just compute them)?
- Can you diagnose complex problems?
- Can you explain your reasoning clearly?
- Do you understand user psychology and game loops?
- Can you balance profit with growth?
