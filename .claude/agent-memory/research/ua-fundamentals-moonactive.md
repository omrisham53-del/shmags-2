9. Studio expectations: Technical skills (Excel >> SQL > analytics platforms), soft skills

## Critical Formulas

- LTV = D30 ARPU + (Tail Monthly ARPU × Months)
- CAC = Total Spend / Paying Users
- CPI = Total Spend / Installs
- Payback = CAC / Monthly ARPU
- ROAS Dx = Revenue by day X / Total Spend
- Healthy ratio: CAC:LTV = 1:3 to 1:5

## Interview Red Flags to Avoid

- Confusing CAC with CPI
- Can't calculate LTV
- Can't read cohort tables
- Weak Excel skills
- No understanding of iOS vs. Android differences (post-IDFA)
- Making budget decisions without reasoning

## Practice Path

1. Master one Excel model (LTV, CAC, scaling)
2. Solve 2-3 cohort diagnosis problems
3. Prep for channel trade-off questions
4. Know iOS/Android landscape (tracking, optimization)
