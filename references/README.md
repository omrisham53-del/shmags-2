# References

Standard operating procedures, style guides, and recurring assets.

## Folders

- **brand-assets/** - Fonts, images, icons, colors for consistent branding across projects
- **sops/** - Standard operating procedures and checklists
- **examples/** - Example documents and templates

## When to Add

Add reference material that you find yourself reusing across projects:
- Design/style guides
- Process checklists
- Example documents
- Brand guidelines
- Standard formats

Keep this folder for truly reference material, not active project work.
