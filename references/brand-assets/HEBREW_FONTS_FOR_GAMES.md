# Hebrew Fonts for D&D Games

This guide helps you find and set up Hebrew fonts suitable for D&D campaigns.

## Official D&D Session Font Palette (Locked)

**Use these consistently across all D&D session materials:**

- **Body Text** (character descriptions, dialogue, narrative): **Noto Serif Hebrew**
- **Headers** (session titles, location names, NPC names): **Rubik**
- **Display/Dramatic** (spells, magical effects, dramatic moments): **Heebo**

This palette is applied automatically to all D&D content generation.

## Quick Start: Google Fonts (Hebrew-Verified)

These fonts are confirmed to support Hebrew fully:

### Body Text (Best for character names, descriptions, dialogue)
1. **[Noto Serif Hebrew](https://fonts.google.com/noto/specimen/Noto+Serif+Hebrew)** - Elegant, reads well at any size
2. **[Noto Sans Hebrew](https://fonts.google.com/noto/specimen/Noto%2BSans%2BHebrew)** - Clean, modern, very readable
3. **[Heebo](https://fonts.google.com/specimen/Heebo)** - Contemporary feel, works well for game text
4. **[Alef](https://fonts.google.com/specimen/Alef)** - Distinctive modern design

### Display/Headers (Titles, location names, dramatic text)
1. **[Noto Rashi Hebrew](https://fonts.google.com/noto/specimen/Noto+Rashi+Hebrew)** - Traditional script style, distinctive look
2. **[Rubik](https://fonts.google.com/specimen/Rubik)** - Bold and modern, great for headings

## How to Install

### Option 1: Google Fonts (Recommended)
1. Visit [fonts.google.com](https://fonts.google.com/)
2. Search the font name above
3. Click + (Select this style)
4. Download or use @import in CSS

### Option 2: Advanced - Local Installation
Download fonts and install to Windows:
- Save .ttf files to `C:\Windows\Fonts\` (Windows will auto-detect)
- Or right-click font file > Install
